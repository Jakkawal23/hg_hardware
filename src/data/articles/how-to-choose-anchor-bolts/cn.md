选错膨胀螺栓是安装后脱落或承重不足最常见的原因之一。本文整理了根据墙体材质与承重需求选择合适膨胀螺栓的基本原则。

### 1. 常见膨胀螺栓类型

- **塑料膨胀管（Plastic Anchor）**：适用于轻型作业，如挂画、相框、小型置物架，可用于混凝土墙和石膏板墙。
- **膨胀螺丝（Expansion Anchor）**：承重能力优于塑料膨胀管，适合中轻型结构固定，如扶手、重型置物架，适用于混凝土或轻质砖墙面。
- **化学锚栓（Chemical Anchor）**：利用双组份树脂胶将螺杆与钻孔粘合固定，是所有膨胀螺栓中承重与抗拉强度最高的类型，适合结构性工程、支撑柱或有振动的机械设备安装。
- **石膏板膨胀锚（Hollow Wall Anchor）**：专为空心墙体设计，如石膏板墙，弥补墙体本身无法完全咬合螺纹的问题。

### 2. 根据墙体类型选择

| 墙体类型 | 推荐膨胀螺栓 |
| --- | --- |
| 厚混凝土 / 硬质水泥墙 | 膨胀螺丝、化学锚栓 |
| 轻质加气混凝土砖（AAC） | 专用轻质砖膨胀螺丝 |
| 石膏板墙 / 空心墙 | 石膏板膨胀锚、蝶形锚栓 |
| 瓷砖 / 大理石 | 小号塑料膨胀管，配合非冲击钻头使用 |

### 3. 计算承重需求

选择前应先估算悬挂或固定物品的总重量，并预留至少 2-3 倍的安全系数，尤其是空调、重型置物架等存在振动或反复拉力的安装场景。

### 4. 安装注意事项

- 钻孔尺寸须严格按照包装上标示的规格，不宜过小或过大。
- 安装前清理孔内粉尘，尤其是化学锚栓，孔内清洁与否直接影响胶体粘合效果。
- 拧紧螺丝或螺母时力度适中，避免过紧导致膨胀管破裂或螺纹滑丝。
