全牙丝杆（全螺纹螺杆）广泛用于管道吊装、吊顶安装及轻型结构工程。由于整根杆身均为螺纹，可自由调整螺母位置并按需截断长度，使用非常灵活。

### 1. 安装前的准备工作

- 选择与工程相符尺寸的全牙丝杆（按螺纹直径与螺距选型）
- 与丝杆规格匹配的六角螺母、平垫圈与弹簧垫圈
- 与安装面材质相符的膨胀螺栓（可参考《如何选择合适的膨胀螺栓》一文）
- 切割工具，如手动切管钳或纤维切割片，以及去毛刺锉刀

### 2. 截断丝杆的正确步骤

1. 测量实际所需长度，并预留两端拧紧螺母所需的余量
2. 使用切割工具垂直于丝杆截断，避免切口歪斜
3. 用锉刀打磨切口处变形的螺纹，确保螺母能顺畅拧入拧出

### 3. 固定到结构上的步骤

1. 按设计位置钻孔，并根据基材（混凝土、轻质砖或钢结构）选用合适的膨胀螺栓
2. 将丝杆拧入膨胀螺栓并锁紧，使用铅垂线或水平仪校正垂直度
3. 套入平垫圈与弹簧垫圈后，拧紧螺母固定要悬挂的部件，如管道支架或角铁
4. 从另一侧再拧紧一颗锁紧螺母（双螺母锁紧法），防止因振动而松动

### 4. 注意事项

- 运输与存放过程中避免丝杆弯曲变形，否则会导致螺母拧入困难，承重效果也会下降
- 对于重载吊装，建议加装弹簧垫圈或尼龙锁紧螺母以提高安全性
- 务必确认螺纹尺寸与所搭配的螺母、膨胀螺栓一致，避免打滑或松脱

选用优质全牙丝杆并按正确方法安装，能有效延长吊装系统使用寿命，降低施工现场的安全风险。
