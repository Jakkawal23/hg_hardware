# วิธีอัปโหลดรูปสินค้า

รูปสินค้าทุกชิ้นเก็บอยู่ใน `public/products/` แยกเป็นคนละโฟลเดอร์ต่อ **1 สินค้า** โดยใช้ชื่อโฟลเดอร์ตรงกับ
**รหัสสินค้าถาวร** (ตัวเลข เช่น `01-01-01-002`) — รหัสเดียวกับที่ปรากฏใน URL ของหน้าสินค้านั้น
(`/th/products/01-01-01-002`) **ไม่ใช่ SKU** เพราะ SKU อาจเปลี่ยนชื่อได้ในอนาคต แต่รหัสตัวเลขนี้ไม่มีวันเปลี่ยน

ระบบจะสแกนโฟลเดอร์นี้อัตโนมัติตอน build/dev — แค่วางไฟล์รูปให้ถูกชื่อ ถูกโฟลเดอร์ ก็จะขึ้นแสดงในหน้าเว็บทันที
**ไม่ต้องแก้โค้ดหรือไฟล์ JSON ใดๆ ทั้งสิ้น**

## โครงสร้างโฟลเดอร์

```
public/products/
  01-01-01-002/          <- ชื่อโฟลเดอร์ = รหัสสินค้า (ตัวเลข, ตรงกับ URL)
    cover.jpg             <- รูปปก (บังคับ 1 รูป, แสดงเป็นรูปหลัก/รูปในการ์ดสินค้า)
    1.jpg                 <- รูปในแกลเลอรี ลำดับที่ 1 (ไม่บังคับ)
    2.jpg                 <- รูปในแกลเลอรี ลำดับที่ 2
    ...
    8.jpg                 <- สูงสุด 8 รูป (1.jpg - 8.jpg)
  01-01-01-003/
    cover.png
    1.webp
  03-02-02-1PN32A-01/     <- (ตัวอย่างรหัสของอีกสินค้าหนึ่ง)
    cover.jpg
```

## กติกาการตั้งชื่อไฟล์

- ชื่อโฟลเดอร์ = ค่า `slug`/`id` ของสินค้า (ดูได้จากไฟล์ `src/data/products/.../*.json` ฟิลด์ `"slug"`
  หรือดูจาก URL หน้าสินค้านั้นตรงๆ ก็ได้)
- ชื่อไฟล์รูปปก: **`cover`** เท่านั้น (ห้ามสะกดผิด)
- ชื่อไฟล์รูปแกลเลอรี: ตัวเลข **`1` ถึง `8`** เท่านั้น จะข้ามเลขไหนก็ได้ (เช่นมีแค่ `1.jpg` กับ `3.jpg` ก็ใช้ได้
  ไม่จำเป็นต้องเรียงต่อเนื่อง) ระบบจะแสดงตามลำดับเลขน้อยไปมาก
- นามสกุลไฟล์ที่รองรับ: `.jpg`, `.jpeg`, `.png`, `.webp` (เลือกใช้นามสกุลไหนก็ได้ต่อไฟล์)
- ไม่มีรูปคือไม่เป็นไร — สินค้าที่ยังไม่มีรูปจะแสดงรูป placeholder ให้อัตโนมัติ ไม่ต้องสร้างโฟลเดอร์ว่างไว้ล่วงหน้า

## สรุปขั้นตอนอัปโหลด

1. หารหัสสินค้า (เช่น `01-01-01-002`) จาก URL หรือไฟล์ JSON ของสินค้านั้น
2. สร้างโฟลเดอร์ `public/products/<รหัสสินค้า>/` (ถ้ายังไม่มี)
3. ใส่รูปปกชื่อ `cover.jpg` (หรือ .png/.webp) ลงไป
4. (ถ้ามี) ใส่รูปเพิ่มเติมชื่อ `1.jpg`, `2.jpg`, ... ได้สูงสุด 8 รูป
5. รัน `npm run dev` (หรือ `npm run build`) ใหม่ — รูปจะขึ้นแสดงในหน้ารายการสินค้าและหน้ารายละเอียดสินค้าทันที

โค้ดที่สแกนโฟลเดอร์นี้อยู่ที่ [`src/lib/products.ts`](../src/lib/products.ts) ฟังก์ชัน `getProductImages()`
