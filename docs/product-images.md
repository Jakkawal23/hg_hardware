# วิธีอัปโหลดรูปสินค้า

โฟลเดอร์สำหรับวางรูปสินค้า **ถูกสร้างไว้ให้ครบทุกสินค้าแล้ว** (3,984 โฟลเดอร์) อยู่ใต้ `public/products/`
จัดเรียงซ้อนกันตามหมวดหมู่หลัก → หมวดหมู่ย่อย → กลุ่มสินค้า (ตรงกับไฟล์ `.json` ใน `src/data/products/`) →
โฟลเดอร์ของสินค้าแต่ละชิ้น (ชื่อ = **รหัสสินค้าถาวร** เช่น `01-01-01-002` — รหัสเดียวกับที่ปรากฏใน URL
`/th/products/01-01-01-002`, ไม่ใช่ SKU เพราะ SKU อาจเปลี่ยนได้ในอนาคต)

**ไม่ต้องสร้างโฟลเดอร์เอง** — แค่หาโฟลเดอร์ของสินค้าที่ต้องการ แล้ววางไฟล์รูปลงไปตามชื่อ pattern ด้านล่าง
ระบบจะสแกนโฟลเดอร์นี้อัตโนมัติตอน build/dev **ไม่ต้องแก้โค้ดหรือไฟล์ JSON ใดๆ ทั้งสิ้น**

## โครงสร้างโฟลเดอร์

```
public/products/
  <main_category_slug>/              เช่น 01-jin-gu-jian
    <sub_category_slug>/             เช่น 01-01-quan-ya-si-gan
      <group_id>/                    เช่น 01-01-01-quan-ya-si-gan (ตรงกับชื่อไฟล์ .json ไม่มีนามสกุล)
        <product_slug>/              เช่น 01-01-01-002 (โฟลเดอร์นี้ถูกสร้างไว้ให้แล้ว)
          cover.jpg                  <- รูปปก (บังคับ 1 รูป, แสดงเป็นรูปหลัก/รูปในการ์ดสินค้า)
          1.jpg                      <- รูปในแกลเลอรี ลำดับที่ 1 (ไม่บังคับ)
          2.jpg                      <- รูปในแกลเลอรี ลำดับที่ 2
          ...
          8.jpg                      <- สูงสุด 8 รูป (1.jpg - 8.jpg)
        01-01-01-003/
          cover.png
          1.webp
```

ตัวอย่างเต็ม: สินค้ารหัส `01-01-01-002` (สตัดเกลียวตลอด มาตรฐานจีน 6*3*50) → วางรูปที่
`public/products/01-jin-gu-jian/01-01-quan-ya-si-gan/01-01-01-quan-ya-si-gan/01-01-01-002/cover.jpg`

## กติกาการตั้งชื่อไฟล์

- ชื่อไฟล์รูปปก: **`cover`** เท่านั้น (ห้ามสะกดผิด)
- ชื่อไฟล์รูปแกลเลอรี: ตัวเลข **`1` ถึง `8`** เท่านั้น จะข้ามเลขไหนก็ได้ (เช่นมีแค่ `1.jpg` กับ `3.jpg` ก็ใช้ได้
  ไม่จำเป็นต้องเรียงต่อเนื่อง) ระบบจะแสดงตามลำดับเลขน้อยไปมาก
- นามสกุลไฟล์ที่รองรับ: `.jpg`, `.jpeg`, `.png`, `.webp` (เลือกใช้นามสกุลไหนก็ได้ต่อไฟล์)
- ไม่มีรูปคือไม่เป็นไร — สินค้าที่ยังไม่มีรูปจะแสดงรูป placeholder ให้อัตโนมัติ (โฟลเดอร์ที่มีแต่ `.gitkeep`
  จะถูกมองข้ามเหมือนไม่มีรูป)

## หาโฟลเดอร์ของสินค้าที่ต้องการ

เพราะรหัสสินค้า (เช่น `01-01-01-002`) ไม่บอกว่าเป็นสินค้าอะไร เวลามีรูปจริงจากซัพพลายเออร์แล้วอยากรู้ว่า path
เต็มของโฟลเดอร์คืออะไร ให้เปิดไฟล์ [`docs/product-image-lookup.csv`](./product-image-lookup.csv) ด้วย
Excel/Google Sheets — เป็นตารางรายชื่อสินค้าทั้งหมด จัดกลุ่มตามหมวดหมู่หลัก/หมวดหมู่ย่อย พร้อมชื่อไทย-จีน,
SKU, รหัสสินค้า และ path โฟลเดอร์เต็มให้ครบทุกแถว ค้นหา/กรองตามชื่อสินค้าหรือหมวดหมู่ได้เลย แล้วคัดลอก path
ในคอลัมน์สุดท้ายไปวางไฟล์รูปได้ทันที

## สรุปขั้นตอนอัปโหลด

1. เปิด `docs/product-image-lookup.csv` หาสินค้าที่ต้องการ คัดลอก path โฟลเดอร์
2. วางรูปปกชื่อ `cover.jpg` (หรือ .png/.webp) ลงในโฟลเดอร์นั้น
3. (ถ้ามี) ใส่รูปเพิ่มเติมชื่อ `1.jpg`, `2.jpg`, ... ได้สูงสุด 8 รูป
4. รัน `npm run dev` (หรือ `npm run build`) ใหม่ — รูปจะขึ้นแสดงในหน้ารายการสินค้าและหน้ารายละเอียดสินค้าทันที

## เมื่อมีสินค้าใหม่เพิ่มเข้ามาทีหลัง

ถ้ามีการเพิ่ม/ลบสินค้าใน `src/data/products/` ให้รันคำสั่งต่อไปนี้เพื่อสร้างโฟลเดอร์รูป (และอัปเดตตาราง
lookup) ให้ตรงกับข้อมูลล่าสุด — สคริปต์จะสร้างเฉพาะโฟลเดอร์ที่ยังไม่มีเท่านั้น ไม่ลบรูปที่อัปโหลดไว้แล้ว:

```
node scripts/generate-product-image-folders.js
node scripts/generate-product-image-lookup.js
```

โค้ดที่สแกนโฟลเดอร์รูปอยู่ที่ [`src/lib/products.ts`](../src/lib/products.ts) ฟังก์ชัน `getProductImages()`
